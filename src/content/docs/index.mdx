plugged.host is a free host for game servers, bots and small services. It runs on its own panel: a
fork of [Calagopus](https://calagopus.com) (Rust and React, MIT) with everything plugged.host adds
written into its source: self-service servers within an allowance, credits and tokens, Minecraft
and FiveM tools, idle-server parking, node failover from off-node backups, abuse protection,
Discord rewards, the neo assistant and the data for a status page. Its nodes run a matching fork of
Calagopus Wings. Both are open source:
[plugged-host/panel](https://github.com/plugged-host/panel) and
[plugged-host/wings](https://github.com/plugged-host/wings). These pages explain how to run them
yourself.

## Where to go

- **New install:** read the [introduction](/start/introduction/) and the
  [requirements](/start/requirements/), then follow the [install order](/start/install-order/).
- **One feature:** every plugged.host feature has a page with what it does, what it needs, its
  setup and its settings: see the sidebar, from Nodes to Discord and AI.
- **The basics** the fork leaves as Calagopus has them (eggs, locations, databases, backups, mail,
  OAuth): the [Calagopus documentation](https://calagopus.com/docs).
- **Something broke:** Admin › Overview › Health, then [troubleshooting](/panel/troubleshooting/).

## Getting help

Ask in the [plugged.host Discord](https://discord.gg/plugged-host-1502647500295635085) or open an
issue on [GitHub](https://github.com/plugged-host/panel/issues). Report security problems
privately, as the repository's
[security policy](https://github.com/plugged-host/panel/blob/main/SECURITY.md) describes, never in a
public issue.
