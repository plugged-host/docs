plugged.host is a free host for game servers, bots and small services. Under the hood it is an
unmodified [Pelican Panel](https://pelican.dev) and a set of plugins that add everything else:
self-service servers and plans, credits, Minecraft and FiveM tools, idle-server hibernation,
storage mirrors with automatic node failover, abuse protection, Discord rewards, an AI assistant
and a status page. The plugins are open source in
[plugged-host/plugins](https://github.com/plugged-host/plugins), and these pages explain how to
set them up yourself.

## Where to go

- **New install:** read the [introduction](/start/introduction/) and the
  [requirements](/start/requirements/), then follow the [install order](/start/install-order/).
- **One plugin:** every plugin has a page under **Plugins** with what it does, its settings and its
  commands.
- **Something broke:** run [`plugged-host:doctor`](/panel/doctor/), then see
  [troubleshooting](/panel/troubleshooting/).

## Getting help

Ask in the [plugged.host Discord](https://discord.gg/plugged-host-1502647500295635085) or open an
issue on [GitHub](https://github.com/plugged-host/plugins/issues). Report security problems
privately, as the repository's
[security policy](https://github.com/plugged-host/plugins/blob/main/SECURITY.md) describes, never in a
public issue.
